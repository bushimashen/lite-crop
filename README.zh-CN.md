# LiteCrop · 图片裁剪

**单文件 · 零依赖 · 纯浏览器本地处理** 的图片裁剪工具。双击 `index.html` 即用，图片永远不会被上传到任何服务器。

[English](README.md)

## ✨ 功能

- **固定比例一键切换**：自由 / 16:9 / 16:10 / 4:3 / 3:4 / 9:16 / 1:1——锁定比例后拖动任何把手都保持比例
- **精确调整**：四角 + 四边共 8 个把手缩放；框内拖动移动位置、图外拖动平移画布；滚轮 / 滑杆缩放（以鼠标位置为锚点）；三分构图线辅助；框角实时显示输出尺寸
- **原图分辨率输出**：裁剪直接从**源图取样**，预览放大缩小完全不影响成品清晰度
- **双格式导出**：PNG（无损、保透明）或 JPG（质量 50%~100% 可调、体积小）
- **三种输入**：点击选择 / 拖拽 / Ctrl+V 粘贴截图
- **零上传零依赖**：单个 HTML 文件，无构建、无 CDN、离线可用；自动跟随系统深浅色

## 🚀 使用

无需安装：

1. **双击** `index.html` 即可使用
2. 或本地起个静态服务：`npx serve .` / `python -m http.server`
3. 或扔到任意静态托管（GitHub Pages / Gitee Pages / 自己服务器）

## 🧠 实现原理

裁剪框存储在**图像自然坐标系**（`x/y/w/h`），显示时按 `自然坐标 × scale + pan` 换算；导出时用 `drawImage` 直接从源图对应区域取样——4000px 宽的照片哪怕预览缩到很小，导出依旧是原始分辨率。

指针事件采用 `requestAnimationFrame` 合帧（封顶屏幕刷新率），松手时冲刷未落地事件——即使 1000Hz 电竞鼠标高速拖拽也不卡顿、不丢末端位置。
